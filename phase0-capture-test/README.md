# 阶段 0：B站声音采集测试

验证一件事：用安卓 10+ 的内部音频采集（AudioPlaybackCapture），能不能录到 B站 App 播放的声音。
如果录不到，「以南译」就要改用备选方案：在自己的 App 里输入直播间号直接播放。

## 构建

需要 Android Studio（自带 JDK 17 和 Android SDK）。

1. 用 Android Studio 打开 `phase0-capture-test` 文件夹，等 Gradle 同步完成。
2. 手机打开开发者选项里的 USB 调试，连上电脑。
3. 点运行（绿色三角），App 会装到手机上，名字是「以南译 采集测试」。

也可以在命令行构建（需要设置好 `JAVA_HOME` 为 JDK 17、`ANDROID_HOME` 为 SDK 路径）：

```
gradlew.bat assembleDebug
```

生成的 APK 在 `app/build/outputs/apk/debug/app-debug.apk`。

## 测试步骤

1. 打开 App，录音范围选「只录 哔哩哔哩」（装了 B站 时默认就是这个）。
2. 点「开始采集」，允许录音权限和录屏授权。
3. 点「打开 B站」，播放一个有声音的直播或投稿视频。
4. 切回 App 看音量条：
   - 在跳动，结论显示「录到了声音」→ B站 允许被录，方案可行。
   - 一直是静音 → 可能被 B站 禁止录音。改选「所有 App」再试一次：
     如果这时能录到其他 App 的声音、唯独 B站 静音，就说明 B站 禁止了。
5. 点「保存最近 15 秒」，用文件管理器到提示的路径找到 WAV 文件播放，确认声音清楚。

把结论（哪台手机、安卓版本、B站 版本、能否录到）告诉我，用来决定下一步方案。
